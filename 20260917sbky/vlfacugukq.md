# 【揭秘】那些让你彻夜难眠的日子  发生了什么?

> 更新时间：2026-09-17 (UTC+8)

春天来了，阳光明媚，我们却在打哈欠。

不知从什么时候起，我也进入了失眠者的行列，晚上睡不着，白天困得要死、头晕、乏力......

**有这些症状，说明你已经失眠了**

1. 常常会早醒，在黑暗中突然醒来、醒来后不能再入睡，脑海中反复出现一些不愉快的往事或对前途忧心忡忡；

2. 入睡困难，中途易醒、多梦；

3. 早晨起床后无清晰感、不能恢复充沛精力；

4. 工作与学习能力下降，记忆力下降，注意力不能集中等；

5. 白天头昏、疲乏、无力或瞌睡等。

**失眠也分轻重，原来我是急性失眠！**

根据病程，我们也可以把失眠分为**急性失眠**（病程小于4周）、**亚急性失眠**（病程大于4周小于6个月）和**慢性失眠**（病程大于6个月）三部分。

失眠的朋友们，看看你是哪一种呢？

**失眠无小事，要高度警惕睡眠障碍的可能，**我们应该怎么办呢？

**1. 及时到专科医院及综合医院心理科就诊**

河北省人民医院心理科采取家庭支持治疗、药物治疗、物理治疗、心理治疗等综合治疗手段进行调整。

**2. 每个人还需要掌握科学的睡眠卫生常识**

每天准时起床（包括节假日）；

睡在床上的时间不要超过睡眠障碍以前的时间；

避免服用对中枢神经有兴奋作用的食物和药物（如咖啡、浓茶、烟酒等）；

白天不午睡；

起床后进行体育锻炼；

入睡前不阅读带刺激性的书报杂志；

入睡前温水淋浴，按时进食、晚餐不宜过饱；

入睡前做放松活动，如按摩、推拿、静坐、气功等；

卧室环境要舒适，避免强光、噪音、温度适宜（18-24摄氏度）。

想要摆脱失眠，就要养成好的生活习惯哦，如果您有失眠的问题，欢迎拨打**心理科****电话：85988915（病区）/ 85989952（医生办公室）**进行免费咨询。
