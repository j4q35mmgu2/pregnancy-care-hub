# 家有宝贝，面对疫情如何预防？——看看中医儿科专家怎么说

> 更新时间：2026-09-17 (UTC+8)

从2019年12月底起，一场“肺炎”疫情从湖北武汉开始蔓延开来。防疫保卫战也同时打响。从目前公布的感染数据来看，儿童新型冠状病毒感染人数不多，但是儿童是易感人群，最小的感染患儿是刚出生数十小时的婴儿，因此对于儿童的防护不可掉以轻心。

**01.**

> > >

**新型冠状病毒是怎么传播的？**

< < < 

●

《黄帝内经》云：“五疫之至，皆相染易，无问大小，病状相似”，

“不相染者，正气存内，邪不可干，避其毒气，天牝从来”。原来2000多年前的《黄帝内经》就告诉我们很多传染性疾病都是通过呼吸道（天牝，即鼻子）传播的，而且还告诉我们防护的方法。

**新型冠状病毒主要通过呼吸道飞沫和接触传播，也有通过气溶胶和消化道传播的可能。**飞沫传播是指咳嗽、打喷嚏或说话产生的直径大于5微米的含水颗粒，可以飞行一定的距离（一般为＜1米）后接触易感人群的鼻腔等黏膜表面从而导致感染。接触传播通常是指用接触过病毒的手揉鼻子、眼睛、嘴巴等部位导致病毒通过黏膜进入人体。

**02.**

> > >

**如何预防呢？**

< < <

●

**1.首先是要“避其毒气****”**。传染病防治的原则就是三条：“控制传染源，切断传播途径，保护易感人群”。**儿童也是新型冠状病毒的易感人群**，防疫专家给了很多的建议和指引，譬如不去公共场所，居家减少外出，戴口罩，勤洗手，不握手，居家要通风，家庭物品消毒，等等......这么多的指引，最关键的就是：**“戴口罩，勤洗手，待在家，不外出”。**还有加热（56℃以上）、75%酒精、含氯消毒剂都是非常适合普通家庭使用的消毒方法。

图片均来自于国家疾控中心官网

2.**其次是是“正气存内”**。什么是正气呢？“正气存内，邪不可干”，这个正气，可以理解为我们平时所说的“免疫力”以及人体自我调节、平衡的能力。中医还有另外一个词来表达，就是“阴平阳秘”。想让我们的孩子保持“正气存内”，少生病、不生病的状态，要食饮有节，起居有常，还要适当运动！有些家长有个误区会认为孩子胃口好，营养好，多吃肉，免疫力就强了——当然不是！均衡饮食才是健康的基石，“膳食金字塔”（下图适用于3岁以上儿童）......中医脾胃为后天之本，“欲得小儿四时安，常要三分饥与寒”，饮食清淡，营养均衡是首要的饮食准则。多吃肉一定程度上加重孩子的脾胃负担，“饮食自倍，肠胃乃伤”，吃得太多会损伤脾胃，脾胃一伤，往往百病丛生。

**3.脾旺则四季不受邪**

所以，对于儿童来说，**“正气存内”的关键要素就是脾胃健运，首先表现为消化好！**判断孩子是否消化好，有一些简单的方法，舌苔薄白，没有口气，胃口正常，排便正常，睡眠好；反之舌苔厚腻、口气重，大便臭秽，夜间磨牙哭闹，腹胀肠鸣，胃口近期变差或突然很好，都可能是脾胃功能失常的表现！这种情况下，当适当减少食物总量2-3天，以防止积食，也可煲“三星汤”[谷芽10g、麦芽10g、山楂5g（3岁儿童量）]，消滞茶[谷芽10g，麦芽10g，莱菔子10g（3岁儿童量，尤其适用于大便臭秽，舌苔厚腻者）]、苹果山楂水[100g苹果，山楂3g，冰糖适量]。如果发现孩子饮水量增多，或者唇红偏干，舌尖红，多提示内热，可以给“萝卜爽”[白萝卜250g、红萝卜100g、马蹄50g]，同时短时间内适当减少肉类摄入量。

消化不好是脾失健运的主要表现，当然，脾失健运还有很多其他症状，我们这里没法一一列出。但要纠正一些认识上的**误区**：

（1）脾胃虚弱，要健脾补脾，多吃太子参、红枣、北芪、淮山等才是正解？

孩子脾胃功能不好，多有“脾虚”的因素存在，但多数孩子脾虚的原因是“饮食自倍”，所以消导助运才是正解，“脾健贵在运而不在补”，所以健脾益气的药膳对于孩子来不是普适的，反而容易出现各种“上火”表现。岭南地域儿童脾虚夹湿、脾虚夹滞，脾虚夹热的特别多，也就是单纯脾虚证少见，兼夹实邪多见，所以健脾益气药膳当慎重，必须在医生指导下进行！

（2）忽略合理运动、规律作息对脾胃的促进作用：中医认为“脾主四肢肌肉”，脾胃好的孩子，肌肉会比较“结实”，而不会肌肉松软、细弱无力，运动能力会比较强。反之，多运动可以促进脾胃功能。有人会奇怪，中医不是说“劳则耗气”吗？但中医也告诉我们“久卧伤气”，“久坐伤肉”，“久视伤血”，不运动，电子读物时间太长，是可以损伤脾胃、耗伤气血的！合理的有氧运动，达到一定的运动强度和时间，并持之以恒，能促进新陈代谢，促进生长发育，增强心肺功能，促进神经系统、免疫系统的发育，有利于身心健康！从中医的角度来认识，运动能流通气血，滑利关节，能调畅气机、疏达情志，使骨正筋柔、五脏元真通畅，自然能促进脾胃功能！

WHO建议1-5岁儿童每天轻、中强度的活动时间累积达到3个小时，5岁以上的儿童每天中、高强度的运动至少60分钟。中等强度包括快步走、跑步、跳舞、爬楼梯、自行车、滑板、游泳，高等强度通常相当于竞技运动的强度，如捉人游戏、踢足球、打篮球、跳绳、快跑、快速游泳等。
