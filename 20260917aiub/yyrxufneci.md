# 【一院科普】宫颈癌防治：从病因到行动，每个女性都该知道的真相

> 更新时间：2026-09-17 (UTC+8)

**一、宫颈癌：一个可防可治的癌症**

宫颈癌是全球女性第四大常见癌症，但也是唯一明确病因且可通过疫苗预防的恶性肿瘤。世界卫生组织（WHO）提出“90-70-90”目标：到2030年，90%的女孩在15岁前接种HPV疫苗，70%的妇女在35岁和45岁接受高效筛查，90%的癌前病变和宫颈癌患者得到规范治疗，这一愿景的实现，需要医患共同努力。

二、揭开宫颈癌的“元凶”：HPV感染

1. HPV病毒是主要病因 

99%的宫颈癌与高危型人乳头瘤病毒（HPV）持续感染相关。HPV家族有200多种亚型，其中HPV16和HPV18型致癌性最强，导致70%的宫颈癌。

2. 感染HPV≠患癌 

80%的女性一生中会感染HPV，但90%可通过免疫系统在1-2年内清除。只有持续感染高危型HPV（5-10年）才可能发展为癌前病变或宫颈癌。

3. 感染高危因素 

包括过早性生活、多性伴侣、长期吸烟、免疫缺陷（如HIV感染）等。

**三、阻断宫颈癌的“三重防线”******

第一道防线：HPV疫苗接种 

1.疫苗类型：二价（防16/18型）、四价（防16/18/6/11型）、九价（防9种高危型）。  

2.接种年龄：9-45岁女性，最佳接种年龄为首次性生活前（但已有性生活仍可接种）。  

3.常见误区：  

“打了疫苗不用筛查”：疫苗不能覆盖所有高危型HPV，仍需定期筛查。  

“过了26岁没必要打”：疫苗对未感染的HPV亚型仍有保护作用。  

第二道防线：定期宫颈癌筛查 

1.筛查方案（根据中国指南）： 

25-29岁：每3年一次细胞学检查（TCT）。  

30-64岁：每5年一次HPV检测联合TCT（推荐），或每3年单独TCT。  

65岁以上：若过去10年筛查结果正常，可停止筛查。  

2.筛查异常怎么办： 

HPV阳性+TCT正常：1年后复查。  

HPV16/18阳性或TCT异常：需阴道镜活检。  

第三道防线：癌前病变的早诊早治 

CIN1级（低度病变）：60%可自然消退，建议随访。 

CIN2/3级（高度病变）：需宫颈锥切术（LEEP/冷刀），治愈率超95%。 

**四、警惕症状：这些信号不能忽视**

早期宫颈癌常无症状，出现以下表现需及时就医： 

1.接触性出血（性生活后出血） 。

2.不规则阴道流血或绝经后出血 。

3.白带增多、血性白带或恶臭分泌物 。

4.晚期可能出现盆腔疼痛、下肢水肿等 。

**五、治疗进展：从精准手术到免疫疗法**

1. 早期宫颈癌：手术为主（广泛子宫切除+淋巴结清扫），保留生育功能的手术（如宫颈广泛切除术）适用于年轻患者。 

2. 中晚期宫颈癌：放疗联合化疗（同步放化疗）。 

3. 免疫治疗：PD-1抑制剂（如帕博利珠单抗）为复发/转移患者带来新希望。 

**六、健康建议**

1. 接种HPV疫苗+定期筛查：两者结合可降低90%以上宫颈癌风险。 

2. 安全性行为：使用避孕套、避免多个性伴侣。 

3. 增强免疫力：戒烟、均衡饮食、规律作息。 

4. 消除误区： 

“没有症状就不需要筛查”：早期宫颈癌常无症状。  

“绝经后不会得宫颈癌”：HPV感染潜伏期可达数十年。  

宫颈癌防治是一场“知己知彼”的战役。我们呼吁每位女性：主动接种疫苗、坚持规范筛查、关注身体信号。早预防、早发现、早治疗，让宫颈癌不再是生命的威胁。

（肿瘤科  杨盼盼）
